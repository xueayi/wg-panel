## 已实现的修复（尚需最终综合验证）

### Agent：`agent/wgagent.py`

- 整条写命令外层文件锁，覆盖读取、IP 分配、提交、同步；锁支持同进程重入。
- 写前 `backup/transaction-*` 快照包含 registry、服务端配置、客户端目录；失败恢复完整文件集合。
- registry、服务端配置、新增客户端文件采用临时文件 + fsync + 原子替换。
- `transaction.json` 记录未完成事务，下一次写命令尝试恢复异常中断。
- `managed_conf_sha256` 检测外部配置漂移，普通写操作阻止覆盖。
- agent `plan --request JSON` / `apply --request JSON --revision ... [--confirm]`：revision 绑定请求、磁盘、registry、客户端文件及部分运行时状态；锁内复核。
- 应用后核对运行时 peer、公钥、AllowedIPs、Keepalive 和配置 Endpoint。
- PSK 在客户端重签中保留。
- 纳管阻止未知或重复、无法保留的指令；支持 JSON dry-run 预览与 revision 确认。
- 从共享配置卷 `peer*/*.conf` 推导私钥公钥并匹配 linuxserver 客户端，匹配 PSK 后导入；无匹配私钥禁导出。
- 新增 `configured_endpoint`、`keepalive`、`client_keepalive`、`exportable/export_reason` 等摘要字段。
- 地址和站点路由通过可注入的 ip 命令同步；仅回收面板记录拥有的路由，事务记录逆操作。
- `metrics` 遇接口不可用返回失败，避免失联误判成功。
